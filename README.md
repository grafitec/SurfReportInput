# Surf Report Input

Surf Report Input is a personal data management project built to track surf rides, fuel usage, surf companions, and ride statistics.
The project is designed as a practical learning platform for database management, SQL, data analysis and software development. The application combines a custom PyQt6 user interface, SQLite database storage and analytics powered by Pandas and data visualization libraries.

The user interface is designed using Qt Designer and customized through QSS (Qt Style Sheets) to create a modern and consistent user experience.
## Features

### Surf Reports
- Create and manage surf ride reports
- Track ride duration, weather conditions, surf type and notes
- Register surf companions for each ride
- Store ride metadata in a SQLite database

### Fuel Tracking
- Log fuel purchases and consumption
- Track total fuel usage and costs

### Data Management
- SQLite relational database
- CRUD operations (Create, Read, Update, Delete)
- Linked tables for ride and companion data
- Git and GitHub version control

### Analytics
- Data retrieval using SQL
- Data analysis using Pandas
- Statistical summaries and reports
- Data visualization using Matplotlib
- Planned Plotly dashboard integration

### GPS Data
- Import Apple Watch ride data
- Process TCX files
- Convert and store relevant tracking data for analysis
- Future route visualization and mapping support

## Purpose

The primary goal of this project is to learn and combine:

- Python development
- SQL and database design
- Data management principles
- Data analysis with Pandas
- Data visualization
- Software architecture and project structure
- Version control with Git and GitHub

## AI Usage

Artificial Intelligence tools were used throughout the development process as a learning aid, knowledge source, and troubleshooting assistant.

AI was used to:

- Explain programming concepts
- Provide guidance on Python, SQL, SQLite, PyQt6, Pandas and Git
- Help understand software architecture and database design principles
- Assist with debugging and problem-solving
- Explain best practices and alternative approaches

AI was not used as an autonomous coding agent and did not independently develop the application. All architecture, implementation decisions, database design, user interface design, and code integration were performed manually as part of the learning process.

The goal of using AI was educational: to better understand the technologies involved and to accelerate learning while maintaining full ownership of the project's design and implementation.
